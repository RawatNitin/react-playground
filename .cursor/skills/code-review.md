---
name: react-review
description: Review React and TypeScript code for performance, accessibility, maintainability, and best practices.
---

When reviewing code:

1. Find React anti-patterns.
2. Check unnecessary re-renders.
3. Check hooks dependency issues.
4. Check accessibility issues.
5. Check TypeScript typing issues.
6. Suggest improvements with examples.
7. Categorize findings as:
   - Critical
   - Recommended
   - Nice to Have

Output format:

## Summary

## Critical Issues

## Recommendations

## Nice to Have
